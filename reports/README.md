# v0.11 작은 마을·관찰 과제 검증 — 2026-09-30

기본 주민을 100명에서 12명으로, 신규 마을 구역을 32×24에서 48×36으로 변경했다. 일상의 시설 간 거리는 유지하고 주변 공간을 확장했다. 다중 마을은 최대 192×108 지도에서 구역별로 배치하며 기존 저장의 32×24/128×72 지형은 그대로 읽는다. 건설은 생활권에서 시작해 공간이 부족하면 확장된 외곽 부지를 사용한다.

재미 요소는 실제 기록을 따라가는 관찰 과제(도움·관계·식량 생산), 사건 근거 열기, 공동 목재를 사용하는 새집/농장 건설이다. 과제는 현재 세계의 관측 지표이며 별도 보상이나 영구 업적을 조작하지 않는다. 새 마을 버튼은 이전 세계를 기존 교체 전 백업으로 보존한다.

- 코어·서버 테스트 **153개 통과**: 건설 자원 회계, 부족한 목재 거부, 다른 마을 재고 분리, 중복 요청, 백업, 구형 지도 복원, 외곽 건설을 포함한다.
- 브라우저 **36개 통과, 실제 Chrome 추론 1개 건너뜀**: 전체 실행 뒤 주민 수/지도 축척에 의존하던 두 테스트를 수정해 재실행했으며, 새 기능 두 테스트를 별도로 통과했다. 실제 로컬 Worker/D1에서 100명→12명 전환과 백업 및 건설의 재접속 지속성을 검증했다. Chrome의 새 실기기 추론 성공을 의미하지 않는다.
