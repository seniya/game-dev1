## 재실행과 보고서 보존

명령은 현재 체크아웃한 코드로 실행된다. 과거 명령을 지금 실행해도 그 버전의 결과가 재현된다는 뜻은 아니다. 정확한 이전 재현은 해당 소스 커밋과 환경을 기준으로 한다. 과거 보고서를 다시 생성할 때는 기존 파일을 보존하고 새 버전·조건의 결과를 별도로 기록한다.

`package.json`의 `regression:gatherings`와 `regression:social`은 현재 같은 `src/gatherings-regression.ts`를 실행하고 `recurring-observation-regression.json`을 쓴다. 이름이 gatherings여도 v0.15의 `gatherings-regression.json`을 다시 만드는 명령이 아니다. `--seed 7`처럼 지정하면 시드별 파일을 쓴다. 최신 v0.19 경로는 `npm run regression:biography`이며 `biography-regression.json`(또는 시드별 파일)을 쓴다. 보고서의 버전 라벨만으로 실행 소스가 고정되지는 않는다.

일반 검사: `npm test`, `npm run test:browser`, `npm run build`. 브라우저 테스트는 로컬 시험 세계를 변경하며 운영 사이트를 대상으로 하지 않는다. `npx tsx src/heritage-workerd.ts`는 개발 서버 4174 포트의 로컬 시험 세계를 초기화하는 별도 도구다.

## 주민 들여다보기 읽기 안정성 수정 — 2026-09-30

주민 패널의 매 틱 `innerHTML` 교체를 기존 요소를 유지하는 부분 갱신으로 변경했다. 각 펼침 항목의 열림 상태, 키보드 포커스, 읽는 위치를 유지하며, 관계·기억·생애 기록은 주민/사건 키로 구분한다. 텍스트를 선택한 패널은 최신 갱신을 보류하고 선택 해제 시 적용한다. 상단 프로필 문구의 줄바꿈으로 패널 높이가 바뀌는 경우도 읽던 요소를 기준으로 보정한다.

서버 생애 갱신은 요청 중 기존 기록을 유지한다. 서로 겹치는 자동 조회를 막고, 빈 결과에서도 가족·재산 정보를 지우지 않는다. 주민/탭/세계 전환은 새 내용으로 전환하고 스크롤을 처음으로 이동한다.

브라우저 전체 실행과 수정 후 재검증으로 **40개 시나리오 통과**, 실제 Chrome 추론 1개는 건너뛰었다. 새 회귀 테스트 4개는 데스크톱·모바일의 펼침/스크롤/포커스/텍스트 선택 유지, 선택 해제 후 최신 값 반영, 지연된 생애 응답, 관계 정렬 변경을 검증했다. 글꼴 로딩 완료 후 동일 조건을 3회씩 반복 검증했다. production TypeScript/Worker/UI build를 확인한다. 시뮬레이션 규칙과 저장 형식은 변경하지 않았다.

가뭄 조건은 첫 10일 구간 시작에 3일 가뭄을 갱신하고 11번째 구간에 식량 24개를 투입한다. 100명 조건은 3개 정착지의 초기 재고·농장·자연 자원을 가지므로 v0.5의 한 마을 100명 실험과 직접 비교하지 않는다. 출생·상속·노화가 추가되어 이전 버전의 결과와 달라진다.

100일 Mock: 생존 14명, 출생 2명, 모델 판단 33건. 모든 회계 오차는 0이다.

대규모 전체 이력을 로컬 저장 하나에 넣으면 기존 150MB·100만 사건 한도에 도달한다. 서버는 원본 이력을 D1에 분리하고 화면에는 페이지 단위로 전달한다. 실행 체크포인트에는 현재 기억·관계와 그 인과 근거를 유지하므로 규모와 역사에 따라 체크포인트도 커질 수 있다. 무제한 크기나 모든 기기의 실시간 성능을 보장하지 않는다.

`elapsedMs`는 재실행·저장·복원·검증을 포함한다. `processHeapMB`는 여러 세계 사본과 GC 대기 메모리를 포함한 프로세스 측정이다. 환경에 따라 바뀌며 운영 서버 처리 시간의 보장이 아니다.
