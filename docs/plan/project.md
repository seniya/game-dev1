# 마을 건설 게임 기획서 (가제: 타운빌더)

## 1. 프로젝트 개요

- **장르**: 2.5D 아이소메트릭 샌드박스 마을 건설 게임
- **레퍼런스**: 드래곤 퀘스트 빌더스 (채집→건축→마을 성장 루프를 계승, 스토리텔링과 수동 블록 쌓기는 과감히 제외)
- **한 줄 컨셉**: 스토리 없이, 채집한 자원으로 완성된 건물을 곧바로 지어 마을을 키우고 주민을 늘려가는 캐주얼 타운 빌더
- **세션 성격**: 목표(퀘스트 서사) 대신 "마을 레벨"이 진행의 축. 플레이어는 언제 시작해도 바로 채집→건축 루프에 진입 가능

## 2. 기존 게임 대비 변경점 요약

| 항목 | 드래곤 퀘스트 빌더스 | 본 게임 |
|---|---|---|
| 스토리 | 세계관/퀘스트 서사 중심 | 없음. 대사·컷신 배제, 목표는 UI 수치(마을 레벨)로만 제시 |
| 건축 방식 | 블록 1개씩 직접 배치 | 재료를 모아 블루프린트 선택 → 위치 지정 → 즉시(연출 포함) 완공 |
| 진행 동력 | 챕터별 스토리 목표 | 주민 요청 + 마을 레벨업 보상 |

## 3. 시점 및 그래픽 스타일

- **2.5D 아이소메트릭**: 쿼터뷰 각도(약 30~45도)로 렌더링, 캐릭터/오브젝트는 스프라이트 또는 낮은 폴리곤, 지형은 타일 기반 그리드 위에 표현
- 카메라는 회전 없이 고정 각도 + 줌 인/아웃만 지원 (구현 난이도 최소화)
- 그리드 단위: 지형 1칸 = 캐릭터 이동 1칸 = 건축 배치 최소 단위

## 4. 핵심 게임 루프

1. 마을 밖으로 나가 자원 채집 (벌목/채굴/땅 정리)
2. 마을로 귀환, 창고에 자원 저장
3. 자원이 충분해지면 블루프린트 선택 → 부지에 즉시 건축
4. 건물 완공 시 주민 이주 조건 충족 → NPC 입주
5. 입주한 NPC가 요청(필요 시설/아이템) 제시
6. 요청 완료 시 마을 레벨 상승 → 새 블루프린트/도구/채집 구역 해금
7. 1~6 반복하며 마을 확장

## 5. 시스템 상세

### 5.1 지형 시스템 (땅파기/쌓기)

- 지형은 복셀(정육면체 블록) 그리드로 구성되며, 아이소메트릭 시점으로 렌더링
- **파기**: 삽/곡괭이로 블록 제거 → 흙/돌 인벤토리 획득, 파낸 자리는 빈 공간 또는 아래 레이어 노출
- **쌓기**: 인벤토리의 흙/돌 블록을 다시 배치해 평탄화 또는 둔덕 생성 가능
- 용도: (a) 채굴을 통한 광물 확보 (b) 건축 부지 평탄화 — 블루프린트는 평평한 지면에서만 배치 가능하도록 제한해 지형 변형에 목적성 부여
- 깊이 제한: 지표면 기준 약 5레이어까지만 허용 (무한 채굴로 인한 성능/밸런스 문제 방지)

### 5.2 자원 채집 (채굴/벌목)

- **벌목**: 맵에 배치된 나무 오브젝트를 도끼로 타격 → 목재 드롭. 나무는 일정 시간 후 재생성(리스폰)
- **채굴**: 지형 블록 및 광맥 오브젝트(돌/철광석/희귀광물)를 곡괭이로 채취
- **도구 등급**: 초급/중급/고급 도구로 구분, 상위 도구일수록 채집 속도↑, 상위 자원(예: 철광석 이상)은 상위 도구 필수
- 채집 구역은 마을 레벨에 따라 단계적으로 해금 (초원 → 숲 → 산악 → 동굴 순으로 상위 자원 등장)

### 5.3 완성형 건축 시스템 (핵심 차별점)

기존처럼 블록을 한 칸씩 쌓는 대신, 재료를 모아 완성된 건물을 즉시 짓는 방식:

1. **블루프린트 목록**: 집, 창고, 우물, 농장, 작업대 등 건물별로 사전 정의된 설계도. 각 블루프린트는 필요 자재 목록(예: 통나무 20 + 돌 10)과 바닥 면적(가로×세로 칸수)을 가짐
2. **배치 단계**: 건축 메뉴에서 블루프린트 선택 → 마을 부지 위에 반투명 미리보기(고스트)로 표시 → 평탄한 빈 공간 위에서만 배치 확정 가능
3. **건축 확정**: 필요 자재가 인벤토리/창고에 있으면 확정 즉시 자재 소모, 3~5초 정도의 짧은 "건축 중" 연출(먼지 이펙트+게이지)만 거친 뒤 완성된 건물로 전환 — 칸 단위 조립 과정은 생략
4. **커스터마이징(옵션, 후순위)**: 완공 후 색상/지붕 스타일 등 외형 슬롯을 소수 옵션 중 선택해 교체하는 정도로 제한 (자유 조형은 지원하지 않음)

이 방식은 "짓는 재미"를 블록 쌓기가 아닌 "자재를 모아 마을이 채워지는 성취감"으로 대체하는 것이 핵심 의도.

### 5.4 NPC/주민 시스템

- 특정 건물(집)이 완공되면 조건 충족 시 NPC가 자동으로 이주해 그 집에 거주
- 이주 조건 예시: 집 완공 + 마을 레벨 조건 충족 (스토리 대사 없이 "새 주민이 이주했습니다" 알림만 표시)
- 입주한 NPC는 각자 정해진 시간대에 맵 내를 배회하는 단순 AI(스토리성 대사 없이 짧은 감탄사/말풍선 아이콘 정도만 출력)
- **요청 시스템**: NPC가 주기적으로 "우물이 필요해요", "목재 5개를 주세요" 같은 단순 요청을 제시 → 완료 시 마을 레벨 경험치 또는 재화 보상
- 스토리 없이도 목표 의식을 주기 위한 장치이며, 대사는 최소한의 UI 텍스트로 처리 (컷신/성우 없음)

## 6. 진행 구조 (스토리 대체 장치)

- **마을 레벨**: 건물 수, 주민 수, 요청 완료 수를 합산한 누적치로 산정
- 레벨업 시 보상: 새 블루프린트 해금, 새 채집 구역 개방, 상위 도구 제작 가능
- 엔딩 없이 지속 성장형 구조(샌드박스), 다만 "마을 레벨 10 달성" 같은 명확한 1차 목표를 UI에 상시 노출해 방향성 제공

## 7. UI/UX 고려사항

- 화면 하단: 인벤토리 바 + 채집/건축 모드 전환 버튼
- 건축 모드 진입 시 블루프린트 목록(보유 자재 대비 부족분 빨간색 표시)
- 상단: 마을 레벨 게이지, 미완료 NPC 요청 아이콘 리스트
- 대사창 없음 — 모든 안내는 짧은 토스트 알림과 아이콘으로 처리

## 8. MVP(1차 버전) 범위

**포함**
- 지형 파기/쌓기 (단일 맵, 5레이어 깊이)
- 벌목/채굴 기본 자원 3종(목재/돌/철광석)
- 블루프린트 5종 내외(집 2종, 창고, 우물, 작업대)
- NPC 이주 및 요청 시스템(요청 유형 2~3가지)
- 마을 레벨 1~5 진행

**제외 (후순위)**
- 전투/몬스터
- 건물 커스터마이징
- 여러 맵/섬 이동
- 날씨/계절, 낮밤 사이클

## 9. 향후 확장 아이디어

- 몬스터 침입 이벤트(스토리 없이 방어 미니게임 형태로)
- 지형 변형을 활용한 지형 조각 콘텐츠(정원, 연못 파기 등 장식 목적)
- 다중 맵 확장을 통한 채집 구역 다변화
- NPC 직업 배정(농부/대장장이 등) → 마을 자동 생산 시스템
