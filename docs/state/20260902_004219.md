### 결정한 것

- **이주는 여유가 생긴 뒤 2.5초 지연** — 집을 짓는 순간 주민이 튀어나오면 "이주"라는 느낌이
  없고, 큰 집을 지었을 때 두 명이 동시에 나타나 어색하다. 큰 집도 한 명씩 들어온다.
- **시설 요청은 자동 완료, 납품 요청은 명시적 행동(R)** — 건물이 이미 서 있는 것을 플레이어가
  다시 알려 줄 이유가 없다. 반대로 자재를 자동으로 가져가면 건축용으로 모아 둔 자재가 사라진다.
- **이미 서 있는 시설은 요청하지 않고, 같은 시설을 중복 요청하지도 않는다** — "우물이 필요해요"가
  우물 옆에서 나오면 규칙이 고장 난 것처럼 보인다.
- **NPC 무작위는 `hashNoise(id, rollCount, seed)`** — `Math.random`을 쓰면 같은 상태에서 같은
  행동을 재현할 수 없어 테스트가 불안정해진다.
- **NPC는 경로 탐색을 하지 않는다**(기획서 5.4의 "단순 AI") — 갈 수 있는 인접 칸 중 하나를 골라
  한 칸씩 움직이는 것이 전부다. 목적지가 없으므로 길이 막혀도 곤란해질 일이 없다.
- **알림은 `Game`이 쌓고 UI가 꺼내 간다**(`drainNotices`) — 게임 규칙을 단위 테스트할 때 DOM이
  필요 없다.

### 함께 고친 것

커서 정보 갱신 간격을 250ms → 100ms로 줄였다. FPS는 그대로 250ms다. 커서를 옮겼을 때 표시가
늦게 따라오면 조작이 굼떠 보인다 — 브라우저 확인 스크립트를 쓰다가 체감한 문제다.

## 검증 결과

- `npm run typecheck` / `npm run build` — 통과
- `npm test` — **458개 통과** (28개 파일)
  - `Npc`(11개): 배회 시작, 집 반경 이탈 금지, 사방이 막히면 제자리, **같은 번호면 같은 경로**
  - `Population`(9개): 건축 중인 집으로는 이주 안 함, 즉시가 아니라 지연 후 이주,
    수용 인원 초과 금지, 큰 집에 두 명이 순차 입주, 집을 더 지으면 다시 열림
  - `Requests`(15개): 주민 없으면 요청 없음, 동시 상한, 이미 서 있는 시설 제외, 중복 시설 금지,
    시설 요청 자동 완료, 납품은 자재가 있을 때만, 시설 요청은 납품 대상 아님
  - `Toasts`(7개): 수명, 옅어짐, 상한 초과 시 오래된 것 제거
  - `Game`(+9개): 이주 알림 누적, `drainNotices` 비우기, 주민 오브젝트 출력, 납품 시 자재 차감과 경험치
- **브라우저 실제 확인** — 채집 → 건축 → 이주 → 요청 전체 흐름
  ```
  목재 12 · 돌 4 확보 → 작은 집 착공 ("작은 집 건축 중 5%")
  요청 목록: 철광석 2        ← 주민이 생겨야 요청이 나오므로 이주가 일어난 증거
  R 납품 시도 → 토스트 "낼 수 있는 요청이 없습니다"  ← 철광석 미보유
  ```
  캡처에서 완공된 빨간 지붕 집, 그 옆을 배회하는 주민(플레이어와 다른 색), 상단 요청 칩을 확인했다.

**부분 미검증**: "새 주민이 이주했습니다" 토스트 자체는 브라우저에서 육안으로 잡지 못했다
(수명 3.2초라 폴링 시점을 스쳤다). 토스트 DOM 경로는 다른 알림("낼 수 있는 요청이 없습니다")이
화면에 뜬 것으로 확인됐고, 이주 알림 문구는 `Game` 단위 테스트로 고정돼 있다.

Phase 7의 완료 기준(집을 지으면 주민이 들어오고, 요청을 완료해 보상을 받는다)을 충족한다.
