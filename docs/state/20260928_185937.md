# 탐색 방향 교정 — 현실에서 새로운 경험

- 날짜: 2026-09-28
- 사용자 선호: 게임에 한정하지 않으며, 현실에서 새로운 경험을 해보고 싶다.

## 완료

- 게임 중심 해석을 교정하고 실제 활동 중심 후보 10개를 정리했다.
- [새 방향과 후보](../research/2026-09-28-real-world-experiences.md)에 사용자 선호와 근거를 기록했다.
- 이전 후보는 미채택 상태이며, 새로운 장르·제품·기술 스택도 아직 확정하지 않았다.

## 검증

- 공개 사례 및 공식 기능 설명을 확인했다. 활동을 직접 수행하지는 않았다.
- 문서만 추가했으므로 실행 코드 테스트 대상은 없다. 로컬 링크와 공백 오류를 확인한다.
- 기존 미추적 .gitignore와 .ignore는 포함하지 않는다.

## 다음 할 일

1. 실제 해보고 싶은 활동을 고른다.
2. 장소가 필요한 경우 활동 지역, 가능한 시간, 이동 방법을 확인한다.
3. 기존 도구로 한 번 경험하고 즐거웠던 부분을 기록한다.
4. 반복하고 싶은 경험이 확인된 뒤 지속 프로젝트의 구현 범위를 정한다.
