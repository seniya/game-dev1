# 작업 상태 — 로드맵 03 Phase 5 NPC 직업과 자동 생산

- **일자**: 2026-09-02
- **브랜치**: dev
- **직전 상황**: Phase 4에서 낮과 밤을 넣었다. 밤은 아직 시야만 바꿨다. 테스트 821개.

## 이번에 한 일

기획서 9절의 "NPC 직업 배정 → 마을 자동 생산"을 넣었다. 로드맵이 함께 적어 둔 위험
두 가지를 규칙에 박아 넣는 것이 이 Phase의 핵심이었다. 결정은 ADR 0016에 있다.

### 자동 생산이 채집을 대체하지 않게

| 제약 | 방법 |
|---|---|
| 생산은 느리다 | 목재 14초 / 돌 20초 / 철광석 34초에 하나. 손 채집의 10분의 1도 안 된다 |
| 자리가 제한된다 | 일터 한 채가 자리 하나. 주민이 41명이어도 일터가 없으면 아무도 일하지 않는다 |
| 상위 자원은 못 만든다 | 수정은 아무도 만들지 못한다 — 동굴은 직접 가야 한다 |

"생산이 손 채집보다 한참 느리다"는 것을 테스트가 지킨다.

### 직업은 일터가 정한다

목수(작업대, 레벨 1) · 채석공(**채석장**, 레벨 4, 새 블루프린트) · 대장장이(대장간, 레벨 5).
자원 서열이 해금 순서와 같아 마을이 커질수록 스스로 만드는 것도 한 단계씩 올라간다.

누구를 배정할지는 고르게 하지 않는다 — **가장 가까운 놀고 있는 주민**이 간다. 41명 중
하나를 지목하게 하면 목록 UI가 필요하고 그것은 기획서 7절(대사창 없음)과 맞지 않는다.
배정과 해제는 같은 키(`G`)다.

### 출퇴근은 배회 위에 얹었다

주민에게 **기준점**을 두고 낮에는 일터 앞, 밤에는 집 앞으로 옮긴다. 순간이동이 아니라
기준점만 옮기므로 주민이 걸어서 오간다 — 경로 탐색 없는 기존 배회(기획서 5.4의 "단순 AI")가
그대로 출퇴근이 된다. **밤에는 생산이 멈춘다.** 낮밤이 규칙에 닿는 첫 자리다.

### 생산물은 창고로

인벤토리로 보내면 어디에 있든 짐이 늘어 채집이 막힌다(로드맵 02 Phase 6의 흙 문제와 같은
종류다). 창고가 가득 차면 그 몫은 나오지 않는다 — 넘치는 자원을 쌓아 두면 비우는 일이 또
하나의 잡일이 된다.

### 저장 형식 버전은 올리지 않았다

배정은 사용자의 선택이라 저장해야 하지만 **선택적 필드**로 더했다. 예전 저장에 없으면
"아직 아무 일도 맡지 않았다"로 읽히고 그것이 맞는 해석이다(ADR 0008의 규칙 그대로).
로드맵은 이 로드맵에서 형식이 세 번 바뀔 것으로 봤지만 **두 번으로 줄었다**.

## 남겨 둔 것

**봇이 아직 일터를 쓰지 않는다.** 생산 속도는 측정값이 아니라 판단값이며, 봇에 배정을
넣는 것은 Phase 8의 몫이다.

주민이 걸어서 출근하지만 "도착해야 일한다"는 규칙은 넣지 않았다 — 넣으면 길이 막힌 경우를
다뤄야 하고 그것은 경로 탐색을 부른다.
