# 작업 인수 기록 — 로드맵 08 완료

- **일자**: 2026-09-05
- **브랜치**: `dev`
- **범위**: 방향 우선 즉시 행동과 집 내부 생활 소품

## 완료 내용

- 일반 모드에서 방향키/WASD를 누른 채 `Space`를 누르면 플레이어가 향한 인접 칸에 바로
  행동한다. 멀리 남아 있던 커서가 채집·파기·수리·몬스터 쫓기 대상을 가로채지 않는다.
- 이동 키가 없을 때의 마우스·IJKL 커서 행동은 그대로 유지했고, 건축 모드도 먼 부지를
  정밀하게 골라 배치하는 기존 규칙을 보존했다.
- 작은 집에는 러그·침대·베개·식탁을, 큰 집에는 두 번째 생활 구역과 난로를 추가했다.
  절차적 스프라이트뿐 아니라 스프라이트를 쓸 수 없는 도형 폴백에도 같은 의미의 소품을
  그린다.
- 상시 안내, 도움말, README를 `방향키/WASD + Space` 중심으로 고쳐 IJKL의 역할을 정밀
  겨냥과 건축 부지 선택으로 분명히 했다.

## 기술 결정

- [ADR 0024](../adr/0024-이동-의도-우선-행동.md): 일반 행동은 이동 의도의 앞 칸을 우선하고,
  건축 모드는 기존 커서 우선을 유지한다.

상태로 Space를 입력했을 때 커서가 해당 앞 칸을 가리키고 행동 애니메이션이 시작하는 것도
직접 확인했다.
