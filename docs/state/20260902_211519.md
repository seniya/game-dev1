## Phase 1 — 눈으로 확인 (남은 판단값)

1차 확인에서 결함 여섯 개를 고쳤고, 이번에는 ADR이 판단값으로 남겨 둔 둘을 확인했다.

- **커서 범위 6칸(ADR 0012)** — 최대까지 밀었을 때 화면 좌표 (640, 538), 뷰포트
  1280×661 **안에 있다.** 의도대로다(화면 밖으로 나가면 무엇을 겨냥하는지 보이지 않는다).
  그대로 둔다.
- **하루 4분(ADR 0015)** — 통과 플레이 13.7분에 약 4일이 흐른다. 봇 1분이 사람 8~12분이니
  사람 기준 한 판에 10~15일이다. 밤이 잦지도 드물지도 않다. 그대로 둔다.

**키보드만으로 실제 플레이가 되는지도 화면에서 확인했다** — 벌목(목재 36) → 채굴 →
`E` 예치 → `B` 건축 모드 → 방향키로 부지 → `Space` 배치까지. 지형이 평탄하지 않은 자리는
"평탄한 땅이 아닙니다 — 파거나 쌓아 고르세요"로 이유를 알리고, 평지에 놓자 집이 서고
목표가 "주민이 이주하기를 기다리세요"로 넘어갔다.

- HUD가 반투명이라 몬스터가 뒤를 지나면 글자와 겹쳤다 → 배경을 진하게.
- **요청 아이콘이 "지금 할 일" 줄과 겹쳤다** → HUD 아래로 내렸다(화면에서 발견).

## Phase 4 — 후반의 할 일

로드맵이 "셋 중 한둘만"이라 한 대로 둘을 골랐다.

- **달성형 요청 두 종**(주민 수·일꾼 수). 조건 하나로 판정되고 채워지면 스스로 닫힌다.
  마을이 자라야(주민 4명 이상) 나온다 — 초반에 내밀면 마을 전체의 목표가 요청이 된다.
- **수정 등대**(돌 12 + 수정 4, 레벨 11). 밤 시야를 넓힌다. 수정의 두 번째 소비처이며,
  ADR 0014가 "대장간 하나뿐이면 다녀올 이유가 한 번으로 끝난다"고 남긴 한계를 메운다.
  손상되면 밝히지 못하고, 여러 채여도 상한이 있다.

## Phase 5 — 미측정 구간과 봉쇄 판단

봇에 동굴 왕복·일터 배정·방어 건축을 가르쳤다. 처음에는 **통로 옆까지만 가서 레벨 5에
멈췄다** — 자원은 옆에서 캐지만 통로는 밟아야 한다. 한 걸음을 더 디디게 고치니 레벨 20에 닿았다.

이제 통과 플레이가 이렇게 끝난다:

```
레벨 20 · 13.7분 · 건물 129 · 주민 121 · 요청 40
건물 종류: 창고1 작업대1 작은집121 우물1 대장간1 채석장1 망루2 수정등대1
행동: 이동1636 타격2005 건축129 배정9 동굴왕복8 전투14 수리22
```

**대장간과 수정 등대가 섰다는 것은 봇이 동굴에 다녀왔다는 뜻이다.** 이 조건들을 테스트로
고정했다 — 봇이 쓰지 않는 시스템은 측정되지 않는다.

ADR 0017이 남긴 봉쇄 판단도 확정했다(**ADR 0019**). 길이 막힌 몬스터는 앞을 가로막은 것을
두드리고, **울타리만 무너진다.** 다른 건물은 그대로 상하기만 한다 — 되돌릴 수 없는 손실은
여전히 없다. 봉쇄가 임시 방어가 되면서 방어에 선택이 생겼다.

세 시드 모두 레벨 20에 **12.0~13.7분**.
