# 작업 상태 — Phase 6 완성형 건축 시스템 완료 (핵심 차별점)

- **일자**: 2026-09-01
- **브랜치**: dev
- **직전 상황**: Phase 5 완료. 채집·저장은 되지만 마을에 지을 것이 없었다.

## 이번에 한 일

기획서 5.3의 완성형 건축을 구현했다. 블록을 한 칸씩 쌓지 않고, 자재를 모아 블루프린트를
확정하면 3~5초 건축 시간을 거쳐 완성된 건물이 된다.

### 결정 사항 (ADR 0006)

- **블루프린트는 코드 상수** — 항목이 5개이고 타입 검증이 붙으며 로딩 단계가 없다. JSON이
  이득을 내는 규모가 아니다. `BLUEPRINTS` 배열 하나가 유일한 정의 지점이라 나중에 옮기기도 쉽다.
- **여러 칸 건물은 가장 앞쪽 칸 기준으로 정렬** — ADR 0002가 한계로 남긴 항목을 이 규칙으로
  메웠다. 그 칸보다 `x + y`가 큰 지형은 나중에 그려져 건물을 가리고, 작은 지형은 건물에 가려진다.
- **커서는 점유 영역의 중앙** — 좌상단 기준이면 큰 건물이 커서에서 떨어져 보여 배치 감각이 어긋난다.
- **자재 부족과 배치 불가를 구분** — 미리보기는 둘을 합쳐 유효/무효를 판단하지만, 착공 실패는
  `noMaterial`과 `badPlacement`(+ 구체적 이유)로 나뉜다. Phase 9 토스트가 구체적 안내를 할 수 있다.
- **건축 취소는 두지 않았다** — 기획서에 없고 환불 규칙이라는 새 결정이 생긴다. 실제로 문제가
  되면 Phase 9에서 철거를 넣는다.

좌클릭이 배치 확정, `Escape`로 취소.

## 검증 결과

- `npm run typecheck` / `npm run build` — 통과
- `npm test` — **406개 통과** (24개 파일)
  - `blueprints`(12개): MVP 5종, 집만 주민 수용·창고만 저장 확장, 큰 집이 더 비싸고 늦게 해금,
    건축 시간이 기획서의 3~5초 범위, 해금 목록이 정의 순서 유지
  - `Buildings`(21개): 평탄하지 않으면 거절, 바닥까지 파인 자리 거절, 노드·다른 건물과 충돌 거절,
    바로 옆에 붙여 짓기 허용, **쌓아서 평탄하게 만들면 배치 가능해짐**, 건축 중에도 점유,
    완공 목록은 한 번만, 인접 완공 건물 조회
  - `Game`(+18개): 해금 레벨 판정, 커서 중앙 기준 배치, 자재 부족 시 무효 미리보기,
    부족분 종류·개수 보고, 착공 시 자재 소모, 실패 시 자재 미소모, 창고 완공 시 슬롯 확장
- **브라우저 실제 확인** — 채집 → 건축 전체 흐름
  ```
  건축 모드(자재 없음): 1. 작은 집 2×2 목재 12 (-12) 돌 4 (-4) / 2. 우물 1×1 돌 10 (-10) ...
  돌 12개 채굴 후:      2. 우물 1×1 돌 10          ← 부족분 표시가 사라짐
  배치:                 우물 건축 중 16%
  4초 후:               우물                        ← 완공
  완공 후 패널:         2. 우물 1×1 돌 10 (-8)      ← 자재가 소모됨
  ```
  캡처에서 미리보기 초록 마름모, 건축 중 반투명 골조 + 진행 게이지, 완공 건물을 확인했다.

Phase 6의 완료 기준(자재를 모아 집을 짓고 마을에 건물이 남는다)을 충족한다.
