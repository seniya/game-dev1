# 작업 인수 기록 — 로드맵 07 완료

- **일자**: 2026-09-04
- **브랜치**: `dev`
- **범위**: 넓은 마을, 건축 외형, 직관적인 키보드 이동

## 완료 내용

- 신규 마을 지도 설정을 **48×48**로 확장하고 기본 확대율을 1.15로 올렸다. 화면을 처음
  열었을 때 지도 가장자리가 바로 닿지 않고, 집·시설도 더 크게 읽힌다.
- 방향키와 WASD를 모두 걷기로 만들었다. 기존 키보드 전용 경로를 잃지 않도록 IJKL이
  겨냥을 맡고, 도움말·상시 안내·README를 새 조작으로 고쳤다.
- 절차적 건물 스프라이트와 헤드리스 도형 폴백 모두에 역할 소품을 넣었다.
  - 집: 창문
  - 창고: 상자
  - 우물: 물
  - 작업대: 도구
  - 대장간: 화로
  - 채석장: 돌무더기
  - 울타리: 말뚝
  - 망루: 깃발
  - 수정 등대: 수정
- 건물 인스턴스가 배치 당시의 폭·깊이를 선택적 저장 필드로 남기도록 했다. 현재
  풋프린트는 밸런스·자동 배치를 지키기 위해 그대로 두었고, 이후 크기 조정에도 과거
  저장의 점유·주민 출입·창고 접근은 보존된다(ADR 0023).

플레이어 pose가 `facing: east`, 이동 중 소수 x좌표로 바뀌는 것도 직접 확인했다.
