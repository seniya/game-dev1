# 작업 상태 — 로드맵 03 Phase 7 건물 커스터마이징

- **일자**: 2026-09-02
- **브랜치**: dev
- **직전 상황**: Phase 6에서 밤의 침입과 방어를 넣었다. 테스트 860개.

## 이번에 한 일

기획서 5.3의 후순위 항목이자 ADR 0011이 로드맵 03 후보로 남겨 둔 것 — 건물 외형 슬롯이다.
로드맵이 "가장 싼 Phase, 일정이 밀리면 가장 먼저 덜어낼 항목"으로 적어 둔 대로 작게 넣었다.

### 지붕 색만 바꾼다

기본 · 푸른 지붕(레벨 3) · 초록 지붕(레벨 6) · 황금 지붕(레벨 9). `V`로 겨냥한 건물의
외형을 순환한다.

**벽 색은 바꾸지 않는다.** 벽까지 바꾸면 건물 종류를 구분하는 단서(집은 밝은 흙벽, 대장간은
어두운 돌벽, 채석장은 회색)가 흐려진다 — 외형은 알아보는 것을 방해하지 않아야 한다.
자유 조형은 기획서가 명시적으로 배제한다.

### 규칙에는 아무 영향이 없다

마을 점수도 기능도 방어도 그대로다. **오직 보기 위한 것**이며, 그래서 해금 보상으로 알맞다.
레벨 3·6·9의 해금 목록에 외형이 들어가 레벨업 알림에 함께 뜬다.

### 캐시 키에 외형을 넣었다

로드맵이 미리 짚어 둔 함정이다. 스프라이트 캐시가 `종류:가로:세로`로만 나뉘어 있어 그대로
두면 **같은 종류의 건물이 모두 마지막 외형으로 그려진다.** 키에 외형을 더했고, 테스트가
"외형이 다르면 다른 그림"임을 지킨다.

### 저장

**선택적 필드**로 담았다. 기본 외형(0)이면 아예 담지 않고, 없으면 기본으로 읽힌다.
저장 형식 버전은 그대로 2다 — 로드맵이 세 번 바뀔 것으로 본 형식이 **한 번만 바뀌었다**.

    **규칙 불변**, 저장 왕복, 예전 저장 호환, **캐시 키가 외형별로 나뉨**

ADR 0011이 "진짜 새로움은 로드맵 03이 맡는다"고 남긴 약속을 지키는 자리다.

**가장 중요한 것은 봇이 새 시스템을 실제로 쓰게 만드는 것이다.** 지금 봇은 맵 전환도,
직업 배정도, 야간 방어도, 수리도 하지 않는다. 로드맵 02 Phase 6에서 봇이 평탄화를 하지 않아
12분에 레벨 3에 머물렀던 것과 같은 함정이며, 그것을 고치지 않으면 측정이 거짓이 된다.
