# 다른 방향의 AI 놀이 후보 탐색

- 날짜: 2026-09-28
- 상태: 추가 아이디어 10개 제안, 구현 미착수

## 완료

- 이전 후보와 다른 경험을 요청받아 그림·카메라·산책·음악·시각적 탐험 중심으로 확장했다.
- [후보 10개](../research/2026-09-28-ai-play-alternatives.md)에 반복 동기, 최소 범위, 불확실성을 정리했다.
- 공개 기술 자료와 제작자 글을 참고하고, 확인된 사례와 자체 제안을 구별했다.
- 새로운 장르 선택이나 기술 확정 결정은 하지 않았다.

## 검증

- 문서만 작성했다. 기능 코드와 실행 테스트 대상은 없다.
- 문서 내 로컬 링크와 공백 오류를 확인한다.
- 기존 미추적 .gitignore와 .ignore는 사용자 또는 환경의 변경으로 보고 포함하지 않는다.

## 다음 할 일

1. 10개 중 끌리는 경험 2~3개를 고른다.
2. 각 후보의 실제 입력과 결과 예시를 하나씩 만들어 비교한다.
3. 고른 후보의 5분짜리 놀이 규칙을 정한 뒤 최소 기능과 테스트를 구현한다.
