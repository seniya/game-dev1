# 작업 상태 — 로드맵 05 Phase 6 지붕 없는 건물과 주민의 생활

- **일자**: 2026-09-02
- **확인 방법**: 헤드리스 크롬(CDP)으로 낮·밤 화면을 직접 확인. 스크린샷 41~45장째.
- **직전 상황**: 로드맵 05 계획 수립 직후. 요청은 "건물에 지붕이 없도록, 건물 내부를
  NPC들이 움직이며 생활하는 모습을 보고 싶다".

## 이번에 한 일

로드맵 05에 **Phase 6**을 더하고 곧바로 만들었다. 결정은 ADR 0020에 있다.

### 지붕 대신 뒤쪽 벽과 바닥

카메라를 향하는 면(+x·+y)의 반대편 둘만 벽으로 세우고 앞쪽은 낮은 턱만 남겼다.
벽 윗면에 얇은 띠를 얹어 두께를 줬다.

**벽 높이는 화면에서 두 번 낮췄다.** 처음에는 예전 몸통 높이를 그대로 써서 담장처럼
보였고, 한 번 낮춘 뒤에도 안이 좁았다. 테스트로는 찾을 수 없는 종류다.

### 정렬 기준을 뒤집었다 (ADR 0006 개정)

ADR 0006은 건물 정렬 기준을 **앞쪽 칸**으로 뒀다 — 상자 모양이라 앞을 가려야 맞았다.
지붕이 없어지자 근거가 뒤집혔다: 건물이 나중에 그려지면 **바닥이 그 안의 주민을 덮는다.**
기준을 뒤쪽 칸으로 옮기니 건물이 먼저 그려지고 주민이 그 위에 얹힌다.

### 외형 슬롯이 지붕에서 바닥으로

로드맵 03 Phase 7의 꾸미기(여섯 가지, 레벨 3·6·9·12·18)는 지붕 색이었다. 지붕이 없어지면
꾸밀 자리가 사라지므로 바닥으로 옮기고 해금 문구도 "푸른 바닥"으로 바꿨다.
건물 종류를 알리던 색도 바닥으로 옮기되 **채도를 낮췄다** — 바닥은 지형과 맞닿아 원색이면 튄다.

### 주민이 안에서 산다

| 때 | 어디에 | 반경 |
|---|---|---|
| 낮 · 일자리 있음 | 일터 안 | 1칸 |
| 밤 | 집 안 | 1칸 |
| 낮 · 일자리 없음 | 30초마다 갈림 — 열에 넷은 집 안 | 1칸 / 6칸 |

셋째 줄이 핵심이었다. 무직을 전부 밖에 두면 낮에 집이 늘 비고, 전부 안에 두면 마을이 죽는다.
시간 덩어리마다 결정적으로 갈라 같은 사람이 들락날락한다 — 매 프레임 뽑으면 문턱에서
떨리고, 하루에 한 번 뽑으면 아무도 움직이지 않는다.

## 검증 결과

- `npm run typecheck` / `npm run build` — 통과
- `npm test` — **918개 통과** (911 → 918)
  - `Population`(+4): 밤에는 집 안, 낮·일자리면 일터 안, 무직은 오간다, 같은 덩어리에서는
    같은 판단(문턱에서 떨리지 않는다)
  - `WorldRenderer`(+3): 건물 안 주민이 나중에 그려진다, 지붕 대신 일곱 조각, 외형이 바닥을 바꾼다
- **성능 예산 그대로 통과** — 건물마다 그리는 조각이 늘었지만 후반 규모 테스트가 통과한다
- **브라우저 확인**: 밤에는 주민 9명 중 5~7명이 집 안, 낮에도 집집마다 사람이 보인다.
  59~60fps.

## 남겨 둔 것

- **건물이 낮아졌다.** 지붕이 만들던 마을의 실루엣이 줄었다.
- **주민과 플레이어가 벽을 통과하는 것처럼 보인다.** 예전부터 건물 칸 위를 걸어 지났지만
  (이동 판정이 지형만 본다) 지붕이 없어지며 눈에 보이게 됐다. 통행을 막으면 마을이 미로가
  되므로 그대로 뒀다 — 문으로 드나드는 것처럼 보이게 하는 것은 다음 판단이다.
