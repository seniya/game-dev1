# 새 프로젝트 탐색 — AI 놀이 커뮤니티 조사

- 날짜: 2026-09-28
- 브랜치: dev
- 상태: 조사 완료, 장르 선택과 구현은 미착수

## 완료한 내용

- Reddit과 Hacker News의 프로젝트 소개·이용 후기·비판을 확인했다.
- 조합 발견, 전략 관전, 자유 심문, 코미디 파티, 가족 음악, 역할극 사례를 비교했다.
- 지속적으로 발전시킬 새 프로젝트 후보 6개와 우선 검토 후보 3개를 정리했다.
- 가장 먼저 검토할 후보로 작은 선수 리그를 제안했다. 사용자 선택이나 확정 결정은 아니다.
- 이전 프로젝트의 코드·자산·장르를 기획의 전제로 삼지 않았다.

## 검증 범위

- 공개 원문과 제작자 자료를 읽었다. 서비스를 직접 플레이하지는 않았다.
- 문서만 추가했으며 기능 코드와 실행 테스트 대상은 없다.
- 문서의 로컬 링크, 빈 파일 여부, 공백 오류를 확인한다.
- 도구가 생성한 미추적 graft/는 이번 변경에 포함하지 않는다.

## 다음 할 일

1. 혼자 즐기는 전략·추리와 함께 즐기는 창작·파티 중 끌리는 경험을 정한다.
2. 상위 후보의 실제 플레이를 확인하고 기다림·재시도·재방문 동기를 기록한다.
3. 선택한 후보의 한 판 규칙과 AI가 꼭 필요한 순간을 1페이지로 정한다.
4. 최소 프로토타입을 만들고 기능별 테스트와 3~5명의 초기 플레이 관찰을 진행한다.
5. 실제 API 사용량과 대기 시간을 측정한 뒤 모델과 운영 규모를 정한다.
