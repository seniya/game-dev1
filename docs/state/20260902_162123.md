# 작업 상태 — 로드맵 03 Phase 3 동굴과 희귀 광물

- **일자**: 2026-09-02
- **브랜치**: dev
- **직전 상황**: Phase 2에서 다중 맵 구조를 열었다. 동굴은 **비어 있었다.** 테스트 772개.

## 이번에 한 일

동굴에 **갈 이유**(수정), **자격**(레벨 5 + 고급 곡괭이), **돌아온 보람**(대장간),
그리고 **동굴다움**(어둠)을 넣었다. 결정은 ADR 0014에 있다.

### 수정 — 기획서 5.2의 "희귀광물"

서열을 그대로 이었다. 나무(초급 도끼) < 돌(초급 곡괭이) < 철광석(중급) < **수정(고급)**,
리스폰도 16/26/45/**70**초 순이다. 동굴 분포는 지상보다 촘촘하다 — 멀고 불편한 곳일수록
벌이가 좋아야 갈 이유가 생긴다. 나무는 없다.

배치 규칙은 맵 종류가 아니라 **배치 방식**(`layout: 'surface' | 'cave'`)으로 받는다.
지상은 구역으로 나뉘지만 동굴에는 구역이 없다(구역은 마을 중심에서의 거리, ADR 0005).
광맥은 파낸 바닥에만 놓고 **출구 칸에는 놓지 않는다** — 막히면 나갈 길이 사라진다.

### 동굴과 고급 곡괭이는 같은 레벨(5)에 열린다

하나만 열리면 갈 수는 있는데 캘 것이 없거나 그 반대가 된다. ADR 0007이 "중급 곡괭이와 큰
집이 같은 레벨에 열려야 한다"고 적어 둔 것과 같은 이유다. 맵 해금은 구역 해금과 같이
**레벨에서 파생**되므로 저장하지 않는다.

**나오는 길은 언제나 열려 있다** — 잠긴 맵에 갇히는 상황을 만들지 않는다.

### 대장간 — 갔다 온 보상이 마을에 남는다

돌 14 + 철광석 6 + **수정 3**. 동굴과 같은 레벨에 열려 목록에는 먼저 보이고, 다녀와야 실제로
세워진다. ADR 0011의 "레벨 6~10은 편의"는 그대로다(대장간은 5).

### 어둠 — 장소의 성격이지 탐색의 긴장이 아니다

반경 5칸 안은 밝고 11칸 밖이 가장 어둡다. 사이는 **제곱 곡선**으로 잇는다(선형이면 빛의
경계가 원반처럼 도드라진다). 가장 어두운 곳도 0.8이라 지형의 윤곽은 남는다 — 완전한 암전은
길을 잃게 하고, 조명 아이템은 그것을 위한 자원과 밸런싱을 부른다.

규칙과 표현을 나눴다. `Game.dark`가 "지금 맵이 어두운가"를 답하고, 렌더러는 동굴을 모른 채
**빛의 중심**만 받는다. 화면을 한 번 덮는 방식이라 열 수와 무관하게 비용이 일정하고,
그라디언트를 만들 수 없는 환경에서는 고른 어둠으로 떨어진다(도형 폴백 규칙과 같다).

  - `travel`(+12): 동굴에만 수정, 바닥에만 광맥, 출구는 비운다, 고급 곡괭이 요구,
    지상에는 수정 없음, 대장간 자재, **Phase 3 완료 기준**(캐서 → 나와서 → 짓는다)
  - `light`(신규 7개): 어둠 곡선의 경계와 성질
  - `WorldRenderer`(+4): 빛을 넘길 때만 덮는다, 지형을 다 그린 뒤 덮는다, 그라디언트 폴백
  - `items`·`blueprints`: 수정과 대장간이 목록에 들어온 것을 반영
- **브라우저 실제 확인은 하지 못했다** — 이 환경에 브라우저가 없다.

## 남겨 둔 것

- 수정의 쓸모가 **대장간 한 채**뿐이다. 두 번째 소비처가 없으면 다녀올 이유가 한 번으로
  끝난다. Phase 5(직업)와 Phase 6(방어 시설)이 그 자리를 채울 후보다.
- **봇이 아직 동굴을 쓰지 않는다.** 레벨 10까지 지상만으로 도달하므로 동굴의 분포와 리스폰은
  측정값이 아니라 판단값이다. 봇이 동굴을 쓰게 만드는 것은 Phase 8의 몫이다.
