# ADR 0024 — 이동 키가 눌린 Space는 앞 칸에 행동한다

- **일자**: 2026-09-05
- **상태**: 채택

## 배경

방향키/WASD 이동과 Space 행동이 있어도, 대상은 커서가 결정한다. 플레이어가 이동 방향을
바꾸고 즉시 Space를 눌렀을 때 이전 커서가 남아 있으면 "앞의 나무를 캐기"가 두 단계로
느껴진다. IJKL 정밀 겨냥은 필요하지만 일반 채집의 기본 조작으로 보이면 손이 복잡해진다.

## 결정

일반 모드에서 이동 키가 눌려 있는 동안 Space의 단발·연속 행동은 플레이어의 해당 방향
인접 칸을 우선 대상으로 한다. 이동 키가 없으면 기존 커서 대상(마우스 또는 키보드)을 쓴다.
건축 모드는 먼 부지 배치가 필요하므로 기존 커서 우선 규칙을 유지한다.

## 검토한 대안

1. IJKL을 완전히 제거한다: 건축 부지와 세밀한 수리·철거 대상 선택이 나빠진다.
2. 행동할 때 플레이어를 자동으로 한 칸 이동시킨다: 채집·전투의 인접 규칙과 충돌한다.
3. 이동이 끝난 뒤에만 커서를 앞칸으로 맞춘다: 입력 직후의 가장 흔한 상황을 해결하지 못한다.

## 예상되는 결과

- 방향키/WASD와 Space만으로 앞 대상에 즉시 반응해 조작의 기본 루프가 짧아진다.
- 정밀 겨냥과 마우스 조작은 계속 가능하다.
- 대상 선택은 입력 라우터의 순수한 우선순위 변경이므로 이동·저장·게임 규칙에는 영향이 없다.
