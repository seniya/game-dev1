# Game Roadmap

## 목표

웹 기반 2D 타일 마을 건설 게임을 만든다. 플레이어는 지형 위에 도로와 구조물을 배치하고, 주민 AI는 배치된 구조물과 자원을 인식해 생활, 이동, 작업, 생산 활동을 수행한다.

## 핵심 경험

- 플레이어는 격자형 마을을 직접 설계하고 확장한다.
- 구조물은 단순 장식이 아니라 주민 행동의 목적지와 작업장을 제공한다.
- 주민은 상태와 필요에 따라 집, 작업장, 보관소, 자원 지점 사이를 이동한다.
- 마을은 자원 생산, 운반, 소비 흐름을 통해 점진적으로 성장한다.
- 게임은 브라우저에서 즉시 실행할 수 있는 가벼운 2D 경험을 목표로 한다.

## 주요 기능

### 1. 타일 기반 월드

- 사각 격자 맵
- 땅, 물, 숲, 바위 같은 기본 지형
- 타일 선택, 강조 표시, 배치 가능 여부 표시
- 카메라 이동과 확대/축소

### 2. 건설 시스템

- 도로, 집, 작업장, 창고 같은 기본 구조물
- 구조물별 점유 타일과 입구 타일
- 배치 전 미리보기
- 자원 비용과 건설 완료 상태

### 3. 주민 AI

- 주민별 현재 상태: 대기, 이동, 작업, 휴식
- 필요 기반 행동 선택: 일하기, 쉬기, 자원 운반
- 구조물 인식: 집은 휴식처, 작업장은 업무 장소, 창고는 보관 장소
- 목표 타일까지 경로 탐색

### 4. 자원과 생산

- 기본 자원: 나무, 돌, 식량
- 채집 지점과 생산 구조물
- 창고 보관량
- 건설 비용 지불과 생산 결과 반영

### 5. UI

- 건설 도구 막대
- 선택한 타일 또는 구조물 정보 패널
- 자원 현황 표시
- 주민 상태 확인
- 일시정지와 속도 조절

## 개발 순서

### 단계 1. 실행 가능한 기본 화면

- 웹 앱 초기 구조 구성
- 캔버스 또는 DOM 기반 타일 맵 렌더링
- 고정 크기 테스트 맵 표시
- 타일 호버와 클릭 선택

### 단계 2. 건설 프로토타입

- 건설 도구 UI 추가
- 단일 타일 구조물 배치
- 배치 가능 여부 검사
- 구조물 데이터 모델 정의

### 단계 3. 주민 이동

- 주민 엔티티 표시
- 클릭 또는 자동 목표 지정
- 기본 경로 탐색
- 이동 애니메이션

### 단계 4. 구조물 인식 AI

- 집, 작업장, 창고 역할 정의
- 주민이 구조물 목록에서 목표를 선택
- 상태 머신으로 행동 전환
- 작업과 휴식 루프 구현

### 단계 5. 자원 루프

- 자원 채집 지점 추가
- 주민 작업으로 자원 획득
- 창고 저장과 건설 비용 차감
- 자원 부족 상태 표시

### 단계 6. 게임성 확장

- 여러 구조물 종류 추가
- 주민 수 증가와 역할 분화
- 생산 체인 확장
- 저장, 불러오기, 밸런스 조정

## 첫 구현 목표

첫 번째 플레이 가능한 버전은 다음 조건을 만족해야 한다.

- 브라우저에서 타일 맵이 보인다.
- 플레이어가 집과 작업장을 배치할 수 있다.
- 주민 한 명이 집과 작업장을 인식하고 두 지점 사이를 이동한다.
- 현재 주민 상태가 화면에 표시된다.
