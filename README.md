# Living Small World

주민의 생존·생산·가족·관계가 실제 사건으로 이어지는 관찰형 시뮬레이션입니다. 기본 12명이 48×36칸 마을에서 시작하며, 외부 AI 없이도 생활·출생·상속·이주·교역이 진행됩니다.

현재 앱은 **v0.33.0**, 세계 저장 형식은 **v9**입니다. v1~v8 저장을 변환해서 읽으며 기존 세계를 업데이트만으로 초기화하지 않습니다. [문서 안내](DOCUMENTATION.md)에서 현재 규칙과 과거 개발 기록을 찾아볼 수 있습니다.

배포 주소: [Living Small World](https://living-small-world-observatory.seniya2.chatgpt.site). 최신 저장된 배포 결과는 **Sites 버전 46, succeeded**입니다. [v0.33 배포 보고서](reports/deployment-v033.json). 버전별 배포 상태와 보존 경계는 [검증·배포 보고서](reports/README.md)를 따릅니다. 과거 v0.19의 미확정 진행 손실 기록도 원본 보고서에 보존합니다.

## v0.33의 변화

- 주민 생성에서 남성·여성, 키(cm), 몸무게(kg), 질병저항성(0–100)을 정합니다. 키·몸무게를 비우면 나이에 맞게 생성됩니다. 주민의 **일상·생애** 탭에서 현재 상태를 확인합니다.
- 성장기에 키가 자라고 몸무게는 성장·영양 상태에 따라 변합니다. 질병저항성은 영양·피로·나이를 반영해 발병 위험과 회복 속도에 영향을 줍니다. 수치는 게임용 모델이며 의료 기준이 아닙니다.
- 혈족이 아닌 성인 남녀가 양쪽 모두 신뢰·호감 60 이상, 두려움·원망 25 미만이면 손을 잡고 애정을 표현합니다. 둘이 입주할 수 있는 주거 정원을 확보하면 가족을 이루며 기존 건강·식량·18–45세·2년 출산 간격 조건을 충족하면 자녀가 태어납니다. 다른 배우자가 있거나 한쪽 마음이 부족하면 진행하지 않습니다.
- 애정 표현 → 가족 형성 → 출생을 원인 사건으로 연결합니다. 자녀는 나이에 맞는 신체와 부모의 성장 체격·저항성을 일부 물려받습니다. 기존 세계·가족·원본 사건을 보존하며 빠진 상태만 결정적으로 보충합니다.

## 실행

Node.js 22.12 이상(기존 검증 환경: 24.16), npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소를 엽니다. 기본 주소는 `http://localhost:5173`입니다. 개발 서버도 Worker 런타임과 로컬 D1을 사용하고 `.wrangler/`에 데이터를 보관합니다. 개발용 로그인 대역은 production 빌드에서 제거됩니다. 외부 LLM 계정이나 API 키는 필요 없습니다.

```bash
npm run build
npm run preview
```

빌드는 `dist/server/`의 Worker와 `dist/client/`의 UI를 함께 만듭니다. `/?local=1`은 localStorage/파일로 실행하는 별도 기기 모드입니다. 서버 세계와 자동 병합하지 않습니다.

## 모바일에서 관찰하기

하단 메뉴에서 세계·주민·기록·경제·실험실을 전환합니다. 세계 화면의 **지도 / 주민 상세 / 마을 소식** 바로가기로 원하는 위치로 이동하고, 주민이나 시설을 선택하면 상세를 바로 읽을 수 있습니다. **세계 관리**에서 저장·불러오기, **연결 설정**에서 비접속 진행, **지도 범위·시설 찾기**에서 따라보기와 시설 선택을 펼칩니다. [모바일 UI 개선 계획과 검증](MOBILE_UI_PLAN.md).

## 공정한 NPC 생성

소유자를 포함하여 한 세계에서 직접 만드는 NPC는 사용자당 **최대 5명**입니다. 생성할 때 능력 합계 **최대 200점**을 배분하고 성격·욕망·컨디션·자산도 별도 예산 안에서 고릅니다. 화면에 사용량과 남은 점수가 표시되며 초과 입력은 서버에서도 거절합니다. 기존 주민과 성장 후 능력치는 바꾸지 않습니다.

농사꾼·장인·사교가 시작 유형은 같은 능력 200점을 배분합니다. 두 번째 NPC부터 내 기존 주민과의 시작 친밀도를 상대당 **0–60**, 합계 **120**까지 정할 수 있습니다. 입주 전 인연이 양쪽 기억과 사건으로 남고 이후 관계는 실제 생활에 따라 변합니다. 사망해도 직접 생성 슬롯은 회복되지 않으며 자연 출생 자손은 한도에 포함하지 않습니다. [검토·개발 계획](NPC_CREATION_PLAN.md).

## 함께 관찰하기

**소유자와 초대받은 계정만 로그인·참여**합니다. 소유자는 해당 사이트의 공유 메뉴에서 이메일을 초대합니다. Sites `custom` 접근 정책을 유지합니다.

- 참여자는 같은 세계를 관찰하고 세계당 NPC를 최대 5명 만듭니다. NPC는 기존 주민과 같은 자율 규칙으로 살아갑니다.
- 세계 진행·설정·초기화·개입·내보내기·AI 실행·참여자 관리는 소유자 권한입니다.
- 관심 주민 최대 12명과 마지막 관찰 시점은 로그인 계정·세계별로 저장합니다. 다른 기기로 돌아와 **내 NPC의 새 소식**을 확인할 수 있습니다.
- 개인 관심 목록과 로그인 신원은 세계 JSON에 포함하지 않습니다. 기기 모드의 관심 목록은 로컬 세계 저장에 포함합니다.

권한·초대·개인 기록·내부 링크의 경계는 [공동 세계 안내](SHARED_WORLD.md)를 따릅니다.

## 주민의 삶 읽기

**삶의 소개 → 전환점 → 이어지는 일 → 양쪽 관점 → 함께 만든 역사**를 연결합니다. 현재 목표·어려움·관계, 기록된 원인과 후속 경과, 미결 부탁·약속·빚을 원본 사건에서 확인합니다. 서로 다른 참여자가 만든 주민들의 공동 기록은 내부 링크로 공유할 수 있으며, 받는 사람도 초대 로그인이 필요합니다. 과거에 기록하지 않은 관계 수치나 목표 달성을 만들어 넣지 않습니다. [삶의 이야기 규칙](LIVING_SYSTEM_DESIGN.md).

- **지도와 주민**: 주민·건물·자원을 클릭하거나 목록에서 고릅니다. 정착지/세계 전체/선택 주민 따라보기, 실제 이동 거리와 작업 진행률, 장소의 재고·주거·생산 정보를 확인합니다. 화면의 위치는 서버가 확인한 경로를 보간합니다.
- **일상·기억·관계**: 욕구·성격·행동 후보와 판단 이유, 오늘의 계획, 반복 경험의 성찰과 근거를 읽습니다. 소문·목격·개인 해석을 구분합니다. [기억과 계획](SMALLVILLE_RESEARCH.md).
- **함께하는 약속**: 식사·식량 도움·공동 수확을 제안하고 직접 초대합니다. 최대 2단계 전달, 한 번의 시간 조율과 재수락, 실제 도착·완료, 반복 경험에서 이어지는 정기 제안을 관찰합니다. [공동 활동](COMMUNITY_ACTIVITIES.md).
- **NPC 만들기**: 이름·나이(0~80)·직업·배경·성격·생활 상태·자산·입주할 집과 첫 인사 상대를 정합니다. 머리 9종·소품 7종·의상 5종, 색상·표정·얼굴 특징·배경과 추천 외모를 미리봅니다. 입주는 실제 빈 주거와 서버 검증을 거칩니다.
- **마을과 역사**: 경제 표본, 도시 연대기, 가계도와 계승, 세계의 기록을 읽습니다. 기록 목록은 페이지로 조회하며 관찰 자체는 NPC의 기억이나 선택을 바꾸지 않습니다.

## 내 이웃과 가문

**내 이웃**에서 직접 만든 주민의 위치·행동·생활 문제·관계·공동 목표를 모아 보고 지도에서 따라갑니다. **내 가문**에서는 자신의 주민을 시조로 선택하고 가족·부·기여의 실제 기록을 읽습니다. 아바타가 사망하면 살아 있는 직계 후손을 다음 관찰 아바타로 고를 수 있습니다. 이미 분배한 상속은 다시 지급하지 않습니다.

가계도, 사업 장부·지분, 가업 수련과 다음 목표, 지난 관찰 이후의 사건을 함께 확인합니다. 생성 시 균형·가족·부·공동체 우선순위를 고르며 생성 이후 변경은 소유자에게만 허용합니다. [가문과 계승](DYNASTY_PLAN.md), [가업](FAMILY_LEGACY_PLAN.md), [내 이웃](NEIGHBORS_PLAN.md).

## 가까이 관찰하고 이야기 찾기

**이야기 산책**은 실제 부탁·약속·관계에 근거한 주민을 추천합니다. 읽는 동안 카드는 그대로 유지되고 **새 이야기 찾기**로 갱신합니다. **하루 따라보기**, **가까이 보기**, **작은 순간을 가까이 → 현장 보기**로 주민과 공사·모임·생활 현장을 따라갑니다. **몰입 보기**는 지도를 넓히며 일반 보기 또는 Escape로 돌아옵니다. 관찰 화면 이동은 세계 시간·설정을 바꾸지 않습니다.

기본 마을은 먹거리·채집·집살림으로 시작하며 인구와 수요에 따라 전문화됩니다. 만 4세부터의 외출, 보호자 인계, 친구·배움·도움에 따른 성년 진로, 다툼·중재·부상별 돌봄 대기를 원본 사건에서 확인합니다. [마을 생활](VILLAGE_LIFE_PLAN.md), [공동 돌봄과 성장](GROWING_VILLAGE_PLAN.md).

## 부탁과 개입

식량·옷·주거의 실제 부족에서 주민의 부탁이 생깁니다. 식량 전달/농장 신설, 새 옷/옷 수선, 집 수리/방 확장의 비용과 효과를 비교합니다. 마을의 유한한 자원을 사용하고, 미루기(게임 6시간, 한 번)와 거절도 가능합니다. 직접 지원 효과와 2시간·하루·3일 뒤 생활 측정을 구분하며, 그 사이의 주민 활동과 날씨도 함께 봅니다. 사망·이주·주거 변경 시 해당 비교는 중단합니다.

동시 진행 최대 2건, 게임 하루 새 부탁 최대 2건, 유효기간 3일입니다. 같은 주민·종류의 반복은 최근 12일의 횟수에 따라 3·6·9일 간격을 둡니다. 지원에 따른 수리·확장·신설은 선택 즉시 완료되고 이후 이용·생산은 별도로 관찰합니다. 저장 변환 시 이미 지난 측정값을 소급 생성하지 않습니다.

위치를 지정한 공사는 주민의 현장 노동으로 진행하고 식사·휴식·날씨·임금 기금에 따라 늦어질 수 있습니다. 주민의 새집·농장 공동 사업과 계절 식량 준비도 실제 자원을 사용합니다. 즉시 완료되는 부탁 지원과 위치 공사는 구분합니다. [현장 노동](LIVING_ACTIONS_PLAN.md), [공동 사업](COOPERATION_PLAN.md).

소유자는 **게임 2시간 관찰하고 멈추기**, 가뭄·외부 식량 투입, 시드 초기화를 사용할 수 있습니다. **새집/농장 짓기**는 선택 마을의 공동 목재 12/16개를 사용합니다. **12명의 넓은 마을로 시작**은 이전 세계를 백업하고 새 세계를 만듭니다. 관찰 과제는 실제 도움·관계·생산 기록을 연결합니다.

## 진행과 저장

한 틱은 게임 10분, 하루는 144틱입니다. 새 서버 세계는 일시정지이고 배속은 1×/5×/20×, 1×는 실제 700ms당 한 틱입니다. 서버 화면은 약 2초마다 동기화합니다.

- 일반 진행은 **최대 5분 간격**으로 확정합니다. 2초 동기화는 작은 시계 한 행만 갱신하며 전체 상태·사건·명령 이력을 매번 쌓지 않습니다. 대규모·고배속·사건량에 따른 조기 저장도 있습니다.
- 사용자 개입·설정·일시정지·수동 진행·NPC 생성·AI 결과는 즉시 확정합니다. **세계 저장**은 진행을 확정한 뒤 전체 사건을 포함한 JSON을 스트리밍 다운로드합니다.
- 같은 엔진의 재시작은 저장된 시계로 미확정 진행을 재구성합니다. 엔진 지문이 바뀌면 등록된 정확한 이전 엔진으로 대기 진행을 복구·확정합니다. 등록되지 않은 지문은 마지막 확정 상태를 사용하고, 등록 엔진의 복구 실패는 기존 세계·대기 행과 진단을 보존합니다. 재배포 전에는 가능하면 명시적으로 저장합니다.
- **자리를 비워도 진행**은 기본 꺼짐입니다. 켜면 재접속 첫 동기화에서 최대 게임 하루를 인구별 처리 상한 안에서 반영하고 초과 시간은 버립니다. 상시 백그라운드 실행은 아닙니다.
- 현재 세계 원본 사건은 계속 보존합니다. 직전 세계 백업 1개, 사용자 명령 30일, 완료 AI 감사 7일을 보관합니다.
- 서버 JSON 가져오기는 직접 전송 10MB, 분할 전송 24MB입니다. `.lsw` 아카이브는 전체 100MB·현재 상태 12MB·사건 100,000건까지 지원합니다. 기기 UI 파일은 150MB, 코어/CLI 문자열은 150,000,000 코드 단위·100만 사건 제한입니다. 큰 전체 JSON을 내보낼 수 있어도 같은 파일을 다시 가져올 수 있다는 보장은 없습니다. 서버 직전 백업은 파일 업로드 없이 복원합니다.
- 기기 모드는 30초 간격 자동 저장과 JSON 저장을 지원하고 숨겨진 탭에서는 멈춥니다. 서버 연결 실패 시 새 로컬 세계로 자동 전환하지 않습니다.

정확한 저장·복원·동시성 계약은 [SERVER_WORLD](SERVER_WORLD.md)를 따릅니다.

## 저장 확인과 복원

소유자의 **불러오기 → 저장과 복원**에서 확정 시점·대기 틱, 현재/직전 백업의 사건 수·본문 크기, 최근 30일 운영 표본과 복구 진단을 확인합니다. 본문 100MB부터 주의, 500MB부터 경고하며 이 값은 서비스 한도나 요금 기준이 아닙니다.

가져온 파일은 엔진 검증 후 미리보기를 표시하고 **이 세계로 교체**해야 적용합니다. 분할 전송은 같은 파일을 24시간 안에 다시 선택하면 이어갑니다. 직전 서버 백업을 복원하면 그 세계의 NPC 생성자·개인 기록을 이어 쓰고 현재 세계를 직전 백업으로 둡니다. 복원 후에는 정지·Mock/off로 시작하며 배속·비접속 설정은 유지합니다.

**큰 이력 아카이브 내려받기 (.lsw)**는 전체 해시·원본 사건·현재 상태를 검증하는 별도 형식입니다. 기존 JSON은 `npm run convert:archive -- 원본.json 새파일.lsw`로 검증·변환할 수 있으며 원본을 보존합니다. **검증 기록**은 선택적으로 확정 저장 최대 500회·16MB·30일을 보관하고 현재 세계를 바꾸지 않고 재생 검사합니다. [파일 경로·저장 계약](SERVER_WORLD.md).

## AI 선택

Chrome / 외부 API / Mock / AI 끄기를 구분합니다. 소유자가 Chrome 모드와 **이 기기에서 다운로드·활성화**를 선택하면 기기 가용성을 확인하고 모델을 준비합니다. Chrome은 주민이 아는 영어 구조화 사건에서 허용 목표를 선택하고 서버가 검증해 한국어 이유를 표시합니다. 자유로운 한국어 모델 대화는 별도 검증 범위입니다.

관련 사건은 60초 동안 모으고 실행 후 최소 60초 쉬며 최근 60분 6회·UTC 하루 36회 상한을 적용합니다. 기기 미지원·실패·탭 종료 시에도 일반 시뮬레이션은 계속하며 **외부 API로 자동 전환하지 않습니다**. 초기화/가져오기는 Mock/off를 사용하고 기존 세계에서 사용자가 선택한 모드는 존중합니다.

외부 API는 서버 연결 설정과 명시적 모드 선택이 모두 있을 때만 호출합니다. 설정 예시는 [.dev.vars.example](.dev.vars.example), 공급자 계약·예산·회상 기능은 [LLM 아키텍처](LLM_ARCHITECTURE.md)를 따릅니다. 인증 키는 서버 secret으로만 관리합니다.

주민의 **주민에게 물어보기 / 기억 돌아보기**는 기억 근거에 제한된 별도 한국어 표현 기능입니다. 최근 4회 대화 맥락과 약속 결과를 참고하고, 가능한 모임은 별도 제안 명령으로 실행합니다. Chrome 한국어 지원은 영어 목표 선택과 별도로 기기에서 확인합니다. [표현 계약](LLM_ARCHITECTURE.md).

Chrome 6A는 2026-09-29 **사용자 수용 완료**입니다. 추가 실기기 자동 추론 성공을 뜻하지 않으며, 기존 사용자 기기 증거와 개발 환경의 실패·건너뜀은 [검증 기록](CHROME_AI_VALIDATION.md)에 보존합니다.

## Headless

```bash
# 기본 12명, 중요 사건에서 Mock 판단
npm run simulate -- --days 100 --seed 42
# 모델 없이 100명·여러 마을 실행
npm run simulate -- --days 100 --seed 42 --npcs 100 --llm off
# 저장하고 추가 80일 실행
npm run simulate -- --days 20 --seed 7 --save world.save.json
npm run simulate -- --days 80 --load world.save.json --save world.save.json
```

CLI는 `--npcs 10~3000`, `--llm mock|off`를 지원합니다. 실제 생존·출생·세대·정착지·자원·사회 사건과 처리 시간을 출력합니다. 자원·화폐는 생산·소비·외부 투입을 구별해 회계 처리하며 거래·공유·상속은 소유권 이전입니다. 같은 시드·명령·승인 응답 순서로 재현합니다.

v0.33 릴리스에서 코어·서버 **357개**, 관련 고유 브라우저 **15개**, 3시드 × off/Mock × 365일 **6조건**과 독립 재개 **84회**, production build를 확인했습니다. 브라우저 15개는 해당 변경 영역의 검사이며 전체 브라우저 검사 수가 아닙니다. 실기기 Chrome 추론은 재실행하지 않았습니다. [검증](reports/physiology-validation.json), [장기 회귀](reports/physiology-regression.json), [버전별 증거](reports/README.md).

회귀 스크립트는 `package.json`의 `regression:*` 명령을 따릅니다. 다수 스크립트는 고정된 과거 버전·보고서 경로를 사용하므로 현재 코드로 실행하기 전에 출력 경로와 버전 표기를 확인하고 과거 증거를 덮어쓰지 마세요. 예를 들어 `regression:expansion`은 현재 엔진을 실행하지만 `reports/expansion-regression.json`에 v0.22로 기록합니다.

생존 3,000명·전체 인물 30,000명·정착지 12개는 구현 상한이며 모든 기기의 실시간 성능이나 영구 생존 보장이 아닙니다. 기본 자원 14종·가공 상품 12종·직업 30종과 무직 상태, 5종 주거를 제공합니다. 가축·질병·공동체는 제한된 게임 규칙이며 야생동물은 제한된 먹이·이동·번식 규칙으로 구현했습니다. 전투·상세 개체 생물학·근사 물리 LOD·다중 서버 분산은 포함하지 않습니다.
