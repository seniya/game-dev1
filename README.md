# Living Small World

**스토리가 발생하는 작은 세계.** 주민 12명이 욕구·성격·자원·관계에 따라 살아가는, API 키 없이 실행 가능한 관찰형 시뮬레이션 MVP입니다. 한국어 대시보드와 화면 없는 CLI가 동일한 TypeScript 코어를 사용합니다.

## 실행

Node.js 22.12 이상(검증 환경: 24.16), npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 기본 주소는 `http://localhost:5173`입니다. 외부 LLM 계정이나 API 키는 필요 없습니다. 웹폰트를 불러오지 못해도 시스템 글꼴로 동작합니다.

```bash
npm run build
npm run preview
```

## 관찰하기

- **세계 관찰**: 지도 주민을 클릭하거나 ‘다음 주민’으로 선택합니다. 일상 탭에서 현재 행동과 판단 이유, 후보 Utility 점수, 욕구, 목표와 성격을 확인합니다.
- **관계 / 기억**: 근거를 클릭하면 실제 사건이 열립니다. 원인 사건과 이후 생긴 기억·관계·목표로 이동할 수 있습니다. 잊힌 기억의 원본 사건도 유지됩니다.
- **마을 주민**: 전체 주민을 목록으로 선택할 수 있습니다. 지도 조작 없이 키보드로도 접근할 수 있습니다.
- **세계의 기록**: 중요/사회/경제/전체 필터, 선택 주민 필터, 설명·사건 ID 검색과 이전 기록 보기를 지원합니다.
- **시간**: 일시정지, 한 틱(게임 내 10분), 1×/5×/20×. 1×는 실제 700ms당 한 틱입니다. 숨겨진 탭에서는 진행하지 않습니다.
- **관찰 실험실**: 3일 가뭄, 공동 식량 24개 투입, 시드 재시작, Mock AI 활성화. 개입은 사건 이력으로 남습니다.
- **저장**: 30초 간격 기기 자동 저장, 재접속 시 자동 복원, JSON 내보내기/가져오기. 초기화 전 세계는 별도 백업으로 유지하며 기기 공간 부족 시 파일로 내보냅니다. 장기 실행에서 localStorage 한도를 넘으면 JSON 파일 저장을 사용하세요.

시뮬레이션 코어는 브라우저 DOM, 타이머, 파일 시스템, 네트워크에 의존하지 않습니다. UI는 복제된 snapshot을 읽고 엔진 명령만 제출합니다.

## Headless

```bash
# 기본 12명, 100일, 중요 사건에서만 Mock 판단
npm run simulate -- --days 100 --seed 42

# LLM을 완전히 끄고 실행
npm run simulate -- --days 100 --seed 42 --llm off

# 상태 저장과 이어 실행 (--days는 추가 실행 일수)
npm run simulate -- --days 20 --seed 7 --save world.save.json
npm run simulate -- --days 80 --load world.save.json --save world.save.json

# 인구 압력 실험: 생산 기반은 같은 한 마을로 유지됨
npm run simulate -- --days 100 --seed 42 --npcs 100 --llm off
```

JSON 통계에는 실제 생존 인구·사망·평균 총 식량·창고 재고·공유·절도·갈등·양방향 관계·LLM 처리량이 포함됩니다. 출생은 구현되지 않아 통계를 만들지 않습니다. 관계 순위 점수는 양방향 `(신뢰 + 애정 − 불만)`의 평균으로, 개별 관계 축의 0~100 범위와 다릅니다. `conflicts`는 절도 목격과 연체를 합한 사건 수입니다.

100일 / seed 42 / 주민 12명 / Mock 기준 검증 결과:

| 지표 | 결과 |
| --- | ---: |
| 생존 / 사망 | 12 / 0 |
| 식량 공유 | 21 |
| 절도 / 갈등 | 2 / 2 |
| 사건 이력 | 40,364 |
| Mock 요청 / 완료 | 48 / 48 |
| 평균 총 식량 | 187.38 |

개발 환경에서 시뮬레이션 실행과 통계 계산은 약 0.4초였습니다(환경별 차이 있음). 100명 실험은 약 0.7초, 식량 생산 기반이 인구에 비해 작아 88명 사망·공유 278건·절도 99건이 발생했습니다. 인구 수에 맞추어 자원을 자동 증식시키지 않습니다.

## 한계와 확장 지점

이번 버전은 한 마을의 MVP입니다. Food/Wood, 생산·소비·이동·수면·거래·대여·공유·절도·목격·소문, 6축 관계와 출처가 있는 기억을 구현했습니다. 농장/창고/집 프로젝트는 기존 시설의 단계 개선입니다. 물은 우물에서 무한 공급되는 생존 요소이며 소지 자원은 아닙니다. 건강 악화는 결핍에서 발생하며 별도 전염병 모델은 없습니다. 계절은 30일 단위의 시간 표시이고 생산량은 날씨와 시설 단계에 영향을 받습니다.

외부 OpenAI/로컬 모델 어댑터는 연결하지 않았습니다. `src/llm/provider.ts`의 계약을 서버 어댑터로 구현하면 되며, API 키를 브라우저에 넣지 마세요. Mock의 `generateDialogue` 계약은 제공하지만 일반 Talk은 코어가 처리하며 UI에서 외부 모델 대화를 호출하지 않습니다. 실제 모델 응답의 결정성을 가정하지 않고 **같은 시드 + 같은 명령/승인 응답 순서**를 재현성 계약으로 삼습니다.

사건 전체 이력은 메모리에 보존하므로 수년 단위 대규모 실행에는 파일/DB 아카이브가 필요합니다. 현재 저장 파일은 150MB, 사건은 100만 건까지 검증하며 UI snapshot은 전체 이력을 복제합니다. LOD, Worker, 가족 형성·출생·세대 교체, 여러 마을, 동물/전투/정교한 건축은 후속 범위입니다.
