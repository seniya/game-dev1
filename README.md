# Living Small World

주민의 생존·생산·가족·관계가 실제 사건으로 이어지는 관찰형 시뮬레이션입니다. 기본 12명이 48×36칸 마을에서 시작하며, 외부 AI 없이도 생활·출생·상속·이주·교역이 진행됩니다.

현재 앱은 **v0.22.0**, 세계 저장 형식은 **v9**입니다. v1~v8 저장을 변환해서 읽으며 기존 세계를 업데이트만으로 초기화하지 않습니다. [문서 안내](DOCUMENTATION.md)에서 현재 규칙과 과거 개발 기록을 찾아볼 수 있습니다.

배포 주소: [Living Small World](https://living-small-world-observatory.seniya2.chatgpt.site). 최신 저장된 배포 결과는 **Sites 버전 34, succeeded**입니다. [v0.22 배포 보고서](reports/deployment-v022.json). 버전별 배포 상태와 보존 경계는 [검증·배포 보고서](reports/README.md)를 따릅니다. 과거 v0.19의 미확정 진행 손실 기록도 원본 보고서에 보존합니다.

## 실행

Node.js 22.12 이상(기존 검증 환경: 24.16), npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소를 엽니다. 기본 주소는 `http://localhost:5173`입니다. 개발 서버도 Worker 런타임과 로컬 D1을 사용하고 `.wrangler/`에 데이터를 보관합니다. 개발용 로그인 대역은 production 빌드에서 제거됩니다. 외부 LLM 계정이나 API 키는 필요 없습니다.

```bash
npm run build
npm run preview
```

빌드는 `dist/server/`의 Worker와 `dist/client/`의 UI를 함께 만듭니다. `/?local=1`은 localStorage/파일로 실행하는 별도 기기 모드입니다. 서버 세계와 자동 병합하지 않습니다.

## 함께 관찰하기

**소유자와 초대받은 계정만 로그인·참여**합니다. 소유자는 해당 사이트의 공유 메뉴에서 이메일을 초대합니다. Sites `custom` 접근 정책을 유지합니다.

- 참여자는 같은 세계를 관찰하고 세계당 NPC를 최대 3명 만듭니다. NPC는 기존 주민과 같은 자율 규칙으로 살아갑니다.
- 세계 진행·설정·초기화·개입·내보내기·AI 실행·참여자 관리는 소유자 권한입니다.
- 관심 주민 최대 12명과 마지막 관찰 시점은 로그인 계정·세계별로 저장합니다. 다른 기기로 돌아와 **내 NPC의 새 소식**을 확인할 수 있습니다.
- 개인 관심 목록과 로그인 신원은 세계 JSON에 포함하지 않습니다. 기기 모드의 관심 목록은 로컬 세계 저장에 포함합니다.

권한·초대·개인 기록·내부 링크의 경계는 [공동 세계 안내](SHARED_WORLD.md)를 따릅니다.

## 주민의 삶 읽기

v0.19에서는 **삶의 소개 → 전환점 → 이어지는 일 → 양쪽 관점 → 함께 만든 역사**를 연결합니다. 현재 목표·어려움·관계, 기록된 원인과 후속 경과, 미결 부탁·약속·빚을 원본 사건에서 확인합니다. 서로 다른 참여자가 만든 주민들의 공동 기록은 내부 링크로 공유할 수 있으며, 받는 사람도 초대 로그인이 필요합니다. 과거에 기록하지 않은 관계 수치나 목표 달성을 만들어 넣지 않습니다. [삶의 이야기 규칙](LIVING_SYSTEM_DESIGN.md).

- **지도와 주민**: 주민·건물·자원을 클릭하거나 목록에서 고릅니다. 정착지/세계 전체/선택 주민 따라보기, 실제 이동 거리와 작업 진행률, 장소의 재고·주거·생산 정보를 확인합니다. 화면의 위치는 서버가 확인한 경로를 보간합니다.
- **일상·기억·관계**: 욕구·성격·행동 후보와 판단 이유, 오늘의 계획, 반복 경험의 성찰과 근거를 읽습니다. 소문·목격·개인 해석을 구분합니다. [기억과 계획](SMALLVILLE_RESEARCH.md).
- **함께하는 약속**: 식사·식량 도움·공동 수확을 제안하고 직접 초대합니다. 최대 2단계 전달, 한 번의 시간 조율과 재수락, 실제 도착·완료, 반복 경험에서 이어지는 정기 제안을 관찰합니다. [공동 활동](COMMUNITY_ACTIVITIES.md).
- **NPC 만들기**: 이름·나이(0~80)·직업·배경·성격·생활 상태·자산·입주할 집과 첫 인사 상대를 정합니다. 머리 9종·소품 7종·의상 5종, 색상·표정·얼굴 특징·배경과 추천 외모를 미리봅니다. 입주는 실제 빈 주거와 서버 검증을 거칩니다.
- **마을과 역사**: 경제 표본, 도시 연대기, 가계도와 계승, 세계의 기록을 읽습니다. 기록 목록은 페이지로 조회하며 관찰 자체는 NPC의 기억이나 선택을 바꾸지 않습니다.

## 부탁과 개입

식량·옷·주거의 실제 부족에서 주민의 부탁이 생깁니다. 식량 전달/농장 신설, 새 옷/옷 수선, 집 수리/방 확장의 비용과 효과를 비교합니다. 마을의 유한한 자원을 사용하고, 미루기(게임 6시간, 한 번)와 거절도 가능합니다. 직접 지원 효과와 2시간·하루·3일 뒤 생활 측정을 구분하며, 그 사이의 주민 활동과 날씨도 함께 봅니다. 사망·이주·주거 변경 시 해당 비교는 중단합니다.

동시 진행 최대 2건, 게임 하루 새 부탁 최대 2건, 유효기간 3일입니다. 같은 주민·종류의 반복은 최근 12일의 횟수에 따라 3·6·9일 간격을 둡니다. 지원에 따른 수리·확장·신설은 선택 즉시 완료되고 이후 이용·생산은 별도로 관찰합니다. 저장 변환 시 이미 지난 측정값을 소급 생성하지 않습니다.

소유자는 **게임 2시간 관찰하고 멈추기**, 가뭄·외부 식량 투입, 시드 초기화를 사용할 수 있습니다. **새집/농장 짓기**는 선택 마을의 공동 목재 12/16개를 사용합니다. **12명의 넓은 마을로 시작**은 이전 세계를 백업하고 새 세계를 만듭니다. 관찰 과제는 실제 도움·관계·생산 기록을 연결합니다.

## 진행과 저장

한 틱은 게임 10분, 하루는 144틱입니다. 새 서버 세계는 일시정지이고 배속은 1×/5×/20×, 1×는 실제 700ms당 한 틱입니다. 서버 화면은 약 2초마다 동기화합니다.

- 일반 진행은 **최대 5분 간격**으로 확정합니다. 2초 동기화는 작은 시계 한 행만 갱신하며 전체 상태·사건·명령 이력을 매번 쌓지 않습니다. 대규모·고배속·사건량에 따른 조기 저장도 있습니다.
- 사용자 개입·설정·일시정지·수동 진행·NPC 생성·AI 결과는 즉시 확정합니다. **세계 저장**은 진행을 확정한 뒤 전체 사건을 포함한 JSON을 스트리밍 다운로드합니다.
- 같은 엔진의 재시작은 저장된 시계로 미확정 진행을 재구성합니다. 엔진 지문이 바뀌면 다른 규칙으로 재실행하지 않아 마지막 확정 상태로 돌아갈 수 있습니다. 재배포 전에는 가능하면 명시적으로 저장합니다. v0.22 배포에서는 정확한 v0.21 엔진 보존본으로 해당 버전의 대기 진행을 최초 인증 조회 때 확정하도록 보완했습니다.
- **자리를 비워도 진행**은 기본 꺼짐입니다. 켜면 재접속 첫 동기화에서 최대 게임 하루를 인구별 처리 상한 안에서 반영하고 초과 시간은 버립니다. 상시 백그라운드 실행은 아닙니다.
- 현재 세계 원본 사건은 계속 보존합니다. 직전 세계 백업 1개, 사용자 명령 30일, 완료 AI 감사 7일을 보관합니다.
- 서버 JSON 파일 가져오기는 UTF-8 기준 10MB, 기기/CLI는 150MB·100만 사건 제한입니다. 큰 전체 이력을 내보낼 수 있어도 같은 파일을 다시 가져올 수 있다는 보장은 없습니다. 서버 직전 백업은 파일 다운로드·업로드 없이 복원하므로 파일 10MB 한도를 적용하지 않습니다.
- 기기 모드는 30초 간격 자동 저장과 JSON 저장을 지원하고 숨겨진 탭에서는 멈춥니다. 서버 연결 실패 시 새 로컬 세계로 자동 전환하지 않습니다.

정확한 저장·복원·동시성 계약은 [SERVER_WORLD](SERVER_WORLD.md)를 따릅니다.

## AI 선택

Chrome / 외부 API / Mock / AI 끄기를 구분합니다. 소유자가 Chrome 모드와 **이 기기에서 다운로드·활성화**를 선택하면 기기 가용성을 확인하고 모델을 준비합니다. Chrome은 주민이 아는 영어 구조화 사건에서 허용 목표를 선택하고 서버가 검증해 한국어 이유를 표시합니다. 자유로운 한국어 모델 대화는 별도 검증 범위입니다.

관련 사건은 60초 동안 모으고 실행 후 최소 60초 쉬며 최근 60분 6회·UTC 하루 36회 상한을 적용합니다. 기기 미지원·실패·탭 종료 시에도 일반 시뮬레이션은 계속하며 **외부 API로 자동 전환하지 않습니다**. 초기화/가져오기는 Mock/off를 사용하고 기존 세계에서 사용자가 선택한 모드는 존중합니다.

외부 API는 서버 연결 설정과 명시적 모드 선택이 모두 있을 때만 호출합니다. 설정 예시는 [.dev.vars.example](.dev.vars.example), 공급자 계약·예산·회상 기능은 [LLM 아키텍처](LLM_ARCHITECTURE.md)를 따릅니다. 인증 키는 서버 secret으로만 관리합니다.

Chrome 6A는 2026-09-29 **사용자 수용 완료**입니다. 추가 실기기 자동 추론 성공을 뜻하지 않으며, 기존 사용자 기기 증거와 개발 환경의 실패·건너뜀은 [검증 기록](CHROME_AI_VALIDATION.md)에 보존합니다.

## Headless

```bash
# 기본 12명, 중요 사건에서 Mock 판단
npm run simulate -- --days 100 --seed 42
# 모델 없이 100명·여러 마을 실행
npm run simulate -- --days 100 --seed 42 --npcs 100 --llm off
# 저장하고 추가 80일 실행
npm run simulate -- --days 20 --seed 7 --save world.save.json
npm run simulate -- --days 80 --load world.save.json --save world.save.json
```

CLI는 `--npcs 10~3000`, `--llm mock|off`를 지원합니다. 실제 생존·출생·세대·정착지·자원·사회 사건과 처리 시간을 출력합니다. 자원·화폐는 생산·소비·외부 투입을 구별해 회계 처리하며 거래·공유·상속은 소유권 이전입니다. 같은 시드·명령·승인 응답 순서로 재현합니다.

npm test

npm run build
# 최신 규칙의 3시드 × off/Mock × 365일 및 규모 회귀

v0.22 전체 실행은 코어·서버 **241개**, 브라우저 **70개** 통과, 실제 Chrome 추론 **1개 건너뜀**입니다. 마지막 보완 후 관련 서버 17개·브라우저 7개, 배포 경계 복구 보완 후 관련 서버 29개·브라우저 5개가 추가로 통과했습니다. TypeScript/production build와 365일·대규모 9조건도 통과했습니다. [검증](reports/expansion-validation.json), [회귀](reports/expansion-regression.json), [전체 보고서](reports/README.md).

생존 3,000명·전체 인물 30,000명·정착지 12개는 구현 상한이며 모든 기기의 실시간 성능이나 영구 생존 보장이 아닙니다. 기본 자원 14종·가공 상품 12종·직업 26종과 무직 상태, 5종 주거를 제공합니다. 가축·질병·공동체는 제한된 게임 규칙이며 야생동물은 제한된 먹이·이동·번식 규칙으로 구현했습니다. 전투·상세 개체 생물학·근사 물리 LOD·다중 서버 분산은 포함하지 않습니다.

실제 초대 계정 로그인, 실모델 품질, 서사의 흥미에 대한 사람 평가, production 장기 부하를 로컬 자동 검증 성공으로 계산하지 않습니다. 이후 과제는 [개발 계획](DEVELOPMENT_PLAN.md), 누적 완료 기록은 [TASKS](TASKS.md)를 참고하세요.

### v0.20 · 이야기 산책

마을 지도에서 하루를 바라보다가 **이야기 산책**을 누르면 주민의 실제 부탁·약속·관계로 이어집니다. **하루 따라보기**로 지도에서 만나고, 주민 이름 옆 ☆로 기억해 두세요. **관심 주민** 주제는 내 관찰 목록만 보여 주며, **삶의 이야기**와 **근거 기록**은 기존 원본 기록을 엽니다.

추천에는 관찰 시점이 표시됩니다. 읽는 동안 카드는 그대로이고 **새 이야기 찾기**로 최신 상태를 살펴봅니다. **몰입 보기**는 지도를 넓히며 일반 보기 버튼 또는 Escape로 돌아옵니다. 재생·배속·세계 설정은 바뀌지 않습니다. 첫 관찰 안내의 진행과 접힘 상태는 이 기기의 세계별로 보관하며 **처음 오셨나요?**로 다시 펼칠 수 있습니다. 계정 간 동기화되는 관심 주민 목록과 안내의 기기 저장은 별개입니다.

완료 기준과 결과는 [매력 완성 로드맵](APPEAL_ROADMAP.md)을 따릅니다.

### v0.21 · 저장 확인과 복원

소유자의 **불러오기 → 저장과 복원**에서 확정 시점·대기 틱, 현재/직전 백업의 사건 수·파일 크기를 확인합니다. 집계는 창을 열거나 새로 확인할 때만 수행합니다. 본문 100MB부터 주의, 500MB부터 경고하며 DB 전체 물리 사용량·서비스 한도·요금을 나타내지 않습니다.

파일과 기기 저장은 실제 엔진 검증을 거쳐 시드·날짜·주민·사건·크기를 미리 보여 줍니다. **이 세계로 교체**를 누르기 전에는 적용하지 않고, 그 사이 세계가 변경되면 다시 확인해야 합니다. 직전 서버 백업 복원은 사건 아카이브와 NPC 생성자·개인 관찰을 이어 쓰며 현재 세계를 직전 백업으로 둡니다. 복원 후에는 일시정지, AI는 Mock/off로 시작하며 배속·비접속 설정은 현재 값을 유지합니다. 이후 **세계 저장**으로 별도 파일도 보관할 수 있습니다. [범위·완료 기준](OPERATIONS_PLAN.md).


### v0.22 · 운영 진단과 이어지는 세계

- **저장과 복원:** 서버 처리 지연·오류와 제공되는 물리 DB 용량을 확인합니다. 10MB 초과~24MB 파일은 분할 전송하며, 같은 파일을 다시 선택해 24시간 안에 업로드를 재개합니다. 검증된 미리보기에서 적용해야 세계가 교체됩니다.
- **검증 기록:** 저장 창에서 기록을 시작·중지하고 재생 검사 또는 파일 내려받기를 할 수 있습니다. 확정 저장 최대 500회·16MB·30일을 보관합니다. 검사로 현재 세계가 바뀌지 않습니다.
- **주민 표현:** 주민 정보에서 ‘주민에게 물어보기’와 ‘기억 돌아보기’를 선택합니다. Chrome 한국어 지원은 기기마다 확인하며 Mock과 명시적으로 선택한 외부 API도 지원합니다. 표현과 근거 사건을 함께 확인하세요.
- **마을 변화:** ‘마을 관찰 과제와 건설’에서 빈 부지의 좌표를 골라 건설하거나 주택 부지를 거래합니다. ‘자연·공동체·역사’에서 야생동물의 먹이와 개체 변화를 확인합니다.

기존 세계와 초대 전용 접근, 최대 5분 확정 저장 정책을 유지합니다. 구체적인 규칙·상한·검증 경계는 [v0.22 개발 범위](EXPANSION_PLAN.md)를 따릅니다.
